# Extractors

Tools that build map ZIPs (see [the format](../docs/FORMAT.md)) from existing games. Each one is a
separate project with its own build.

| Folder | Game | Content |
|---|---|---|
| [`warcraft/`](warcraft/) | World of Warcraft | Terrain, liquids and biomes from a local installation; floating islands and caves; buildings as structure templates. Node.js, no dependencies. |
